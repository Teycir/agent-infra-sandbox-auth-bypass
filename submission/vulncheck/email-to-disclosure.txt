Upstream HEAD 7f1afaf re-checked 2026-11-26: still vulnerable, no fix.

Finding
- nginx gateway maps "$request_method:$request_uri" and routes GET requests whose query string
  ends in a static-asset extension (.json, .js, .css, ...) to @proxy_without_auth, which has no
  auth_request. The backend does not re-validate the API key.
- Result: unauthenticated arbitrary file read via /v1/file/download, and an unauthenticated
  WebSocket shell that runs as "gem" with passwordless sudo to root inside the container.
- GET-only: POST endpoints still return 401.

Severity: Critical
CVSS 3.1: 9.8 — CVSS:3.1/AV:N/AC:L/PR:N/UI:N/S:U/C:H/I:H/A:H
CWE-288, CWE-306

Reproduction: https://github.com/Teycir/agent-infra-sandbox-auth-bypass
